# 🎵 Spotify Clone Project

A responsive Spotify-inspired music player interface built using HTML and CSS.
This project recreates the visual layout of a modern music streaming platform
with a clean dark-themed UI.

## 🚀 Features

- 🎧 Spotify-inspired music player interface
- 🏠 Home page with music sections
- 🎵 Recently played and popular music sections
- 🎶 Album and playlist cards
- ▶️ Music player interface
- 🔊 Volume and playback controls UI
- 📱 Responsive design
- 🌙 Dark-themed modern interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
